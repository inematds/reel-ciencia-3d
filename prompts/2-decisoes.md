# 2 · Decisões curtas (uma mensagem por vez)

O Claude já sabe escrever o código. O que ele precisa de você é direção. Cada bloco abaixo é uma decisão.

## D1 · A ferramenta
```text
HyperFrames para o vídeo (legenda, cartões, aparelho e o MP4). Three.js só para o mundo 3D. Não acrescente outra ferramenta nem serviço pago sem me perguntar.
```

## D2 · Fatos primeiro
```text
Antes de animar, faça o fatos.md: cada número e afirmação que vamos mostrar ou dizer, com link da fonte e uma citação curta. Cálculo nosso vira CÁLCULO; estimativa de cientista vira ESTIMATIVA. Sem fonte: DEIXADO DE FORA. Me mostre a lista.
```

## D3 · Uma pergunta, uma resposta
```text
O reel faz uma pergunta: "<E se …?>". A resposta que ele tem que provar: "<uma linha>". Escreva 8 a 10 batidas em escala crescente (você → uma cidade brasileira → o planeta → o espaço) e a volta. Corte toda batida que não ajuda a provar a resposta.
```

## D4 · Um visual
```text
Use o STYLE.md para o visual. Amarelo só em <a coisa principal>. Nada de texto abaixo de 28 px.
```
Sem palavra vaga de gosto ("deixa cinematográfico"). Diga o que quer ver: "câmera mais lenta", "texto maior", "só uma cor".

## D5 · Uma imagem por cena
```text
Antes do render, tire uma imagem parada no meio de cada cena (npx hyperframes snapshot) e me mostre. Espere meu OK.
```

## D6 · Julgar os quadros
```text
Julgue cada imagem com 3 perguntas: dá para ler tudo no celular? A escala é honesta? Há uma coisa clara para olhar? Liste o que falha, com o segundo. Não corrija ainda.
```

## D7 · Uma mudança por vez
```text
Mude só <a coisa> para <o problema sumir>. Mantenha todo o resto. Tire a imagem de novo.
```

## D8 · Julgar o MP4 de verdade
```text
Tire quadros do MP4 renderizado (não da prévia) a cada 3 s, numa folha só, e julgue com as mesmas 3 perguntas. Confira que o último quadro é igual ao primeiro, a duração, 1080x1920 e −14 LUFS.
```
